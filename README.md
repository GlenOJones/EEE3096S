# EEE3096S - Embedded Systems II Practical

Repository for the EEE3096S practical group work at University of Cape Town. This practical involves embedded systems development using an STM32 dev board.

### NOTE:
For Prac 3, both code for F0 and F4 has been included, this is as a redundancy because in actuallity the only line that should be changed for cross-platform compatibility is the library `#include "stm32f4xx.h" ` in each of the main.c files

## Structure
- `/group` - Collaborative work , shared source files
- `/glen` - Individual dev
- `/Iloke` - Individual 
- `/docs` - Documentation and reports
